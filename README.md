A program that writes one line, at most 120 characters: the funniest error message a kitchen toaster shows its owner when something goes wrong.

## The line

> ERROR E09: Bagel frozen solid. I refuse to fight a hockey puck. Thaw it first.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set for a local test run).
